th123_Softpipe

把 东方非想天则（th123.exe）的 D3D9 绘制调用截下来， 用 CPU 软光栅渲染一整帧，再把成品位图交给真正的 D3D9 显示。

实验性项目。性能方向有效，渲染正确性尚未收敛。

管线

每一层都是一个 <div>，靠 CSS 类 .layer 统一外观。 箭头用单独的 .arrow 块。

th123.exe — 32 位进程，D3D9 固定管线，顶点为屏幕坐标
▼
d3d9.dll — 加载器：读取 ini，把调用转给后端，可选加载模组
▼
cpu_d3d9.dll — 本项目主体：截住绘制调用
▼
softrast.h — CPU 软光栅：解码 → 光栅化 → 混合 → 写帧缓冲
▼
d3d9out.h — 锁离屏面 → 拷贝 → UpdateSurface → Present
▼
真 d3d9 — GPU 只负责把成品位图搬上屏

一次绘制

DrawPrimitiveUP(type, count, pVtx, stride)
  ├─ ① 解码顶点（XYZRHW，无需矩阵）
  ├─ ② 入队 SR_Queue()，记录状态快照
  ├─ ③ Present → SR_Flush() 整帧并行光栅
  ├─ ④ LockRect → memcpy → UpdateSurface → Present
  └─ ⑤ TexReleaseHeld() 释放本帧纹理引用

关键常量

名称值说明
SR_MAX_CMD16384单帧绘制命令上限
SR_MAX_THREADS8工作线程上限
MAX_TEX4096纹理池槽位数
行带数核数 × 4下限 4 行/带
离屏面格式D3DFMT_X8R8G8B8与帧缓冲逐像素对应

已知降级路径

  • DrawPrimitive / DrawIndexedPrimitive 仍是桩 —— 用顶点缓冲的绘制不会被渲染。
  • 着色器为空桩（11 pixel + 3 vertex）。
  • SetVertexShader 在对局内出现约 2000 次，尚未查明。

# th123_Softpipe
## 本项目由AI维护，哎呀
简要：
一个使Th123可以使用CPU渲染的工具，带有简单的模组加载功能，兼容SOKUToys的模组格式，使用这个项目不如去使用正经的ModLoader，这个玩意的Bug很多，请自备超分软件来强制游戏使用全屏。

这是一个 **实验性项目** 发生不可预料的问题是**正常的**
## 构建

需要 **Visual Studio 2019+** 的 MSVC（x86 工具链）与 Windows SDK。
或 **检查发行** 那里有**预编译包**
```powershell
.\build.ps1
```
脚本会自动探测 MSVC 与 SDK 路径。
